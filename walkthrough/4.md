# 모바일 음악·사진 등록 호환성 수정

## 원인

PC 브라우저는 MP3와 사진의 MIME 유형을 보통 정확히 전달하지만, iOS와 일부 Android 파일 선택기는 MIME을 빈 문자열 또는 `application/octet-stream`으로 전달할 수 있다.

기존 앱은 `file.type`이 `audio/` 또는 `image/`로 시작하지 않으면 등록을 거부했다. 또한 오류 토스트가 모달 설정창 바깥에 있어 모바일에서는 메시지가 설정창 뒤에 가려졌다. 이 때문에 보호자는 파일을 선택했지만 모든 슬롯이 계속 `음악 없음`으로 보였다.

## 수정

- `file-types.js`에 모바일 파일 형식 정규화 계층을 추가했다.
- MIME이 없거나 일반 형식이어도 다음 확장자를 인식한다.
  - 음악: MP3, M4A, AAC, WAV, OGG, OGA, OPUS, FLAC
  - 사진: JPG, JPEG, PNG, WEBP, GIF
- 추론한 MIME으로 새 `File`을 구성해 기존 OPFS 저장 및 재생 흐름을 그대로 사용한다.
- 파일 선택기의 `accept` 값에도 지원 확장자를 명시했다.
- 파일 인식·저장 오류를 보호자 설정창 내부에 표시한다.
- `file-types.js`를 오프라인 앱 셸에 포함하고 캐시 버전을 `jukebox-shell-v5`로 올렸다.

## 검증

- MIME이 빈 대문자 `.MP3`를 `audio/mpeg`로 복원: 통과
- `application/octet-stream`인 `.jpeg`를 `image/jpeg`로 복원: 통과
- 지원하지 않는 `.txt` 음악 파일 거부: 통과
- 전체 브라우저 테스트 첫 실행: 11/11 통과
- 같은 탭 즉시 재실행: 11/11 통과
- 앱 시작 및 콘솔 오류 없음: 통과

## 기기 재시험 방법

이전 모바일 선택은 실제 저장되지 않았으므로 배포 완료 후 음악과 사진을 다시 한 번 선택해야 한다.

1. 설치된 PWA를 완전히 종료한다.
2. 다시 열고 필요하면 브라우저에서 한 번 새로고침한다.
3. 설정에서 음악 파일을 다시 선택한다.
4. 해당 슬롯에 음악 파일명이 표시되는지 확인한다.
5. 사진을 선택한 뒤 상태가 `사용 가능`으로 바뀌는지 확인한다.
