# 내장 앨범아트와 최대 음량 구현

## 완료 기능

### MP3 내장 앨범아트

- ID3v2.3·v2.4의 `APIC` 프레임에서 JPEG, PNG, GIF, WebP 이미지를 추출한다.
- 직접 선택한 사진은 `manual`, 음원에서 추출한 이미지는 `embedded`로 구분해 저장한다.
- 수동 사진은 음원을 바꿔도 유지한다.
- 내장 이미지는 새 음원의 이미지로 교체하며, 새 음원에 이미지가 없으면 이전 이미지를 제거한다.
- 추출 실패는 음원 등록을 막지 않는다.
- 확인에 사용한 `비처럼 음악처럼.mp3`에는 APIC 앨범아트가 없으므로 이 파일은 사진을 직접 선택해야 한다.

### 보호자 최대 음량

- 설정 화면에 10%~100%, 10% 단위 슬라이더를 추가했다.
- 값 변경 즉시 `<audio>.volume`에 반영하고 IndexedDB에 저장한다.
- DB 버전을 2로 올리고 별도 `settings` 스토어를 추가했다.
- DB v1의 기존 `slots` 데이터는 마이그레이션 중 유지한다.
- 잘못된 저장값은 100%로 복구한다.

## 검증

- 브라우저 자동 테스트 15/15 통과
- APIC 추출, 이미지 우선순위, 이미지 교체·제거, 재복원 검증
- 최대 음량 50%→`audio.volume 0.5`, 재생 중 30%→`0.3` 적용 검증
- DB v1→v2 실제 업그레이드 후 기존 슬롯 보존 검증
- 서비스 워커 캐시 `jukebox-shell-v8`
