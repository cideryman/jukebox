# 보호자용 재생 통계 설계

## 우선순위

1. 전체 주크박스 백업·복원
2. 반복 터치·긴 누르기 입력 안정화
3. 보호자용 재생 통계
4. 앱 아이콘 단순화·현대화

## 집계할 값

- 선택 재생 횟수: 새 카드 선택 후 실제 재생에 성공한 횟수
- 완료 재생 횟수: 곡이 자연스럽게 끝난 횟수
- 누적 청취 시간: 실제 재생 상태였던 시간
- 최근 재생: 마지막 재생 성공 시각

반복 터치로 무시된 입력, 재생 실패, 같은 카드 정지, 일시정지 후 이어듣기는 새 선택 횟수로 세지 않는다.

## 데이터 연결

각 음원에 고유 `trackId`를 부여하고 통계를 이 ID에 연결한다. 사진 교체는 통계를 유지하지만 음원 교체와 슬롯 삭제는 이전 곡의 기록을 새 곡에 물려주지 않는다.

통계는 별도 IndexedDB 스토어에 저장하고 백업·복원 대상에 포함한다. 통계 저장 실패는 음악 재생을 막지 않는다.

## 화면과 개인정보

- 보호자 설정에서만 슬롯별 통계를 표시한다.
- 사용자용 3×3 화면은 바꾸거나 자동 재정렬하지 않는다.
- 전체 누적값만 먼저 제공하고 기간별 차트는 필요성이 확인된 뒤 검토한다.
- 통계는 기기 안에만 저장하며 서버나 외부 분석 서비스로 보내지 않는다.
- 통계를 이용자의 능력 평가나 선택 강요에 사용하지 않는다는 원칙을 유지한다.
