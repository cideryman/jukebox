# 반복 터치와 긴 누르기 대응 설계

## 우선순위

전체 주크박스 백업·복원 다음 작업으로 지정했다. 앱 아이콘 개편보다 실제 사용 안정성에 직접 영향을 주므로 먼저 처리한다.

## 핵심 결정

- 첫 번째 유효한 터치는 기다리지 않고 즉시 실행한다.
- 이후 700ms 동안 추가 입력은 무시한다.
- 무시된 입력이 들어올 때마다 안정화 시간을 다시 700ms 연장해, 계속 두드리는 동안 재생·정지가 반복되지 않게 한다.
- 입력이 멈춘 뒤 같은 카드를 다시 한 번 누르면 정지하는 기존 계약은 유지한다.
- 음악 카드를 오래 누르는 동작은 손을 뗄 때 한 번의 선택으로 처리한다.
- 이동·취소·다중 터치·보조 버튼은 선택으로 처리하지 않는다.
- 보호자 설정 톱니바퀴의 2초 길게 누르기는 별도 상태 기계로 유지한다.

## 피드백 원칙

- 선택 직후 카드 테두리와 밝기로 즉시 반응을 보여준다.
- 반복 입력을 무시할 때마다 글자 토스트나 경고음을 만들지 않는다.
- 입력 안정화 시간은 실제 이용자 관찰을 통해 500~1000ms 범위에서 조정한다.

## 필수 실기기 시나리오

1. 같은 카드 초당 10회 반복 터치
2. 여러 카드 번갈아 반복 터치
3. 3초·10초 긴 누르기
4. 누른 채 카드 밖으로 이동
5. 두 손가락 동시 입력
6. Android와 iPhone의 긴 누르기 컨텍스트 메뉴 억제 확인
7. 키보드·스위치 접근 입력의 반복 키 처리 확인
