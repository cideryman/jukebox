# 보호자 설정 하단 확인 버튼 적용

## 변경 내용

- 의미가 모호했던 설정창 상단의 `×` 아이콘을 제거했다.
- 설정창 하단에 항상 보이는 큰 `확인` 버튼을 추가했다.
- 설정 목록만 스크롤되고 하단 버튼은 별도 행에 고정되도록 설정창을 구성했다.
- 확인 버튼의 접근성 이름은 `설정을 닫고 음악 화면으로 돌아가기`로 지정했다.
- 파일 저장 중에는 버튼이 `저장 중…`으로 바뀌고 비활성화된다.
- 저장 중 배경을 눌러도 설정창이 닫히지 않도록 `closeSettings()`에서 한 번 더 방어한다.
- 앱 셸 캐시를 `jukebox-shell-v6`으로 갱신했다.

파일 선택은 기존처럼 즉시 저장된다. `확인`은 변경사항을 별도로 커밋하는 버튼이 아니라 보호자 설정을 닫고 사용자 음악 화면으로 돌아가는 버튼이다.
