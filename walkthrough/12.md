# 설정 버튼 길게 누르기 개선

## 문제

태블릿에서 우측 상단 설정 버튼을 길게 누를 때, 바로 아래의 앨범 이미지가 브라우저의 이미지 저장 대상으로 인식되는 경우가 있었다.

## 변경

- 설정 아이콘의 보이는 크기(50px)는 유지하고 실제 터치 보호 영역을 68px로 확대했다.
- 설정 버튼 레이어를 가장 위로 올리고, 누르는 동안 포인터를 버튼에 고정한다.
- 손가락이 버튼 가장자리에서 조금 움직여도 길게 누르기가 취소되지 않도록 했다.
- 설정 버튼의 컨텍스트 메뉴와 드래그를 차단했다.
- 앨범 이미지의 포인터 입력, 길게 누르기 메뉴, 드래그를 직접 차단했다.
- 서비스 워커 캐시를 `jukebox-shell-v14`로 갱신했다.

## 확인

- 실제 터치 영역: 68×68px
- 설정 버튼 레이어: `z-index: 100`
- 터치 동작: `touch-action: none`
- 버튼 중앙과 네 가장자리의 터치 대상이 모두 설정 버튼 영역에 포함됨
- 전체 자동 테스트 19개 실행
