# 우선순위 기능 전체 구현 결과

## 1. 전체 백업·복원

- 음원, 수동·내장 이미지, 슬롯 위치, 최대 음량, 재생 통계를 표준 ZIP으로 내보낸다.
- `manifest.json`에 형식 버전, 파일 크기, SHA-256, 원본 파일명과 MIME을 기록한다.
- ZIP CRC, SHA-256, 경로 순회, 중복 슬롯·음원 ID와 형식 버전을 검증한다.
- 복원 파일을 OPFS에 먼저 기록하고 슬롯·설정·통계를 하나의 IndexedDB 트랜잭션으로 커밋한다.
- 커밋 실패 시 임시 파일만 정리하고 기존 주크박스를 유지한다.
- ZIP32 저장 방식이므로 전체 백업과 개별 파일은 4GB 미만이어야 한다. SHA-256 계산 중 메모리 사용량은 가장 큰 단일 파일 크기의 영향을 받는다.

## 2. 반복 터치·긴 누르기

- 첫 입력은 즉시 실행하고 기본 700ms 동안 후속 입력을 무시한다.
- 반복 입력마다 안정화 종료 시간을 연장해 계속 누르는 동안 재생·정지가 반복되지 않는다.
- 긴 누르기는 손을 뗄 때 한 번만 실행한다.
- 큰 이동, 취소, 보조 손가락과 마우스 보조 버튼을 무시한다.
- 키보드·보조공학 click 경로는 유지한다.

## 3. 보호자용 재생 통계

- DB를 버전 3으로 올리고 `stats` 스토어와 곡별 `trackId`를 추가한다.
- 선택 재생, 완료 재생, 실제 청취 시간, 최근 재생을 기기 안에 기록한다.
- 30초 체크포인트와 정지·일시정지·곡 변경·종료 시점에 시간을 저장한다.
- 사진 교체는 통계를 유지하고 음원 교체·슬롯 삭제는 이전 통계를 분리한다.
- 통계 저장 실패는 음악 재생을 막지 않는다.

## 4. 앱 아이콘

- 짙은 남색 배경, 청록색 레코드, 흰색 재생 버튼의 단순한 형태로 교체했다.
- SVG 원본, Android/PWA 192×192·512×512 PNG, iPhone 180×180 Apple Touch 아이콘을 제공한다.
- 512px 아이콘의 핵심 도형을 마스커블 안전 영역 안에 배치했다.

## 자동 검증

- 브라우저 자동 테스트 19/19 통과
- 백업 정상 왕복, 한글 파일명, CRC·SHA 손상, 경로 순회, IDB 강제 실패 검증
- 반복 입력 잠금 연장, 긴 누르기 단일 실행, 이동·다중 입력 취소 검증
- 통계 저장·복구·음원 분리·백업 포함 검증
- DB v1→v3 마이그레이션 후 기존 슬롯 보존 검증
- PWA·Apple 아이콘 파일 존재와 실제 픽셀 크기 검증
