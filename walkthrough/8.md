# 전체 주크박스 백업 기능 우선순위 설계

## 결정

전체 주크박스 백업·복원을 앱 아이콘 개편보다 앞선 최우선순위로 지정했다.

일반적인 서비스 워커 캐시 업데이트는 IndexedDB와 OPFS의 음악을 지우지 않는다. 보호해야 하는 상황은 사용자가 브라우저의 사이트 데이터 또는 설치된 PWA의 앱 데이터를 삭제해 두 저장소가 함께 초기화되는 경우다.

## 백업 목표

- 1~9번 슬롯의 음원, 이미지, 위치와 이미지 출처를 하나의 파일에 저장
- 최대 음량 등 보호자 설정 포함
- Android 다운로드 폴더와 iPhone 파일 앱에 PWA 외부 파일로 보관
- 서버 전송 없이 완전 로컬 동작
- 체크섬과 형식 버전으로 손상·호환성 검증
- 복원 전체가 성공하기 전에는 기존 주크박스를 변경하지 않는 원자적 복원

## 다음 구현 순서

1. 버전 지정 ZIP 매니페스트와 파일 배치 정의
2. 오프라인 스트리밍 ZIP 내보내기
3. 임시 영역 검증 후 원자적으로 교체하는 가져오기
4. 손상·용량 부족·중단 상황 자동 테스트
5. Android Chrome 및 iPhone Safari/PWA 교차 복원 확인

백업 기능 완료 후 반복 터치·긴 누르기 입력 안정화를 진행하고, 그다음 앱 아이콘 단순화·현대화를 진행한다.
