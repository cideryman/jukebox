# 나의 주크박스 — 실험용 PWA 뼈대

사진을 눌러 로컬 음악을 재생하는 3×3 태블릿 주크박스 PWA입니다. 별도 빌드나 외부 라이브러리가 없습니다.

## 실행

서비스 워커와 PWA 설치 기능은 `file://` 주소에서 동작하지 않으므로 localhost로 실행합니다.

```powershell
node server.js
```

그다음 Chrome에서 `http://127.0.0.1:4173`을 엽니다. Antigravity의 미리보기 서버를 사용해도 됩니다. 포트를 바꾸려면 `node server.js 8080`처럼 포트 번호를 뒤에 붙입니다.

## 사용 방법

1. 오른쪽 위 톱니바퀴를 2초 동안 길게 누릅니다.
2. 원하는 칸에 음악 파일을 선택합니다. MP3에 내장 앨범아트가 없을 때만 사진을 추가로 선택합니다.
3. 설정을 닫고 사진을 누르면 재생됩니다.
4. 같은 사진을 다시 누르면 정지하고, 다른 사진을 누르면 음악이 바뀝니다.

## 현재 동작과 제한

- 등록 파일과 최대 음량은 이 브라우저의 로컬 저장소에 보관됩니다. 브라우저 앱 데이터를 삭제하면 함께 지워질 수 있습니다.
- 최대 음량은 앱 내부 출력 비율이며 기기 물리 버튼이나 블루투스 스피커 음량을 잠그지는 않습니다.
- 백그라운드 재생과 잠금 화면 제어는 Android Chrome이 지원하는 범위에서만 동작합니다.
- 계정, 서버, PIN, 4×4 격자, 사용자 프로필은 포함하지 않습니다.
- 실제 제품 단계의 구현 지침은 [`DESIGN.md`](DESIGN.md)에 정리되어 있습니다.
